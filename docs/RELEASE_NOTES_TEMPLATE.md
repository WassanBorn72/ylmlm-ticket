## モ！のチケット帳（非公式） {{TAG}}

ゆるめるモ！のチケット情報をまとめて確認できる、非公式Androidアプリです。会場・チケット代・開場／開演時間を一覧で確認し、購入先のページへ移動できます。ユーザー登録は不要です。

**ゆるめるモ！および各チケットサイトの公式アプリではありません。** 購入前に、料金・日時・販売状況をチケットサイトで確認してください。

### ダウンロード・インストール

**[Android APKをダウンロード](https://github.com/{{REPO}}/releases/download/{{TAG}}/{{APK}})**

1. Androidスマホで上のリンク、またはこのページ下部の **Assets** から `{{APK}}` をダウンロードします。
2. ダウンロードしたAPKを開きます。
3. インストール許可を求められたら、ブラウザーや「Files」など今回使う提供元を許可します。
4. 「モ！のチケット帳（非公式）」を開きます。

更新時は新しいAPKを上書きインストールしてください。お気に入りを残すため、先にアンインストールする必要はありません。

[今回の更新内容・更新履歴](https://github.com/{{REPO}}/blob/{{TAG}}/docs/CHANGELOG.md)

### 今回のアップデート

- 出演者選択の「グループ内ユニット」と「外部コラボ」を「ユニット」にまとめました。
- 一覧・公演詳細もユニット名だけの表示に整理しました。

### 主な機能

- **公演一覧**：会場・券種別料金・開場／開演時間と購入先を確認できます。
- **検索・日付・出演者絞り込み**：公演名・会場名で検索でき、カレンダーから開催日を選べます。出演者も一覧から選択できます。
- **お気に入り**：ハートで登録・解除し、掲載中の登録公演をまとめて確認できます。
- **新着**：新しく見つかった公演を `NEW` と「新着」に表示します。初回取得では新着にしません。
- **購入先**：公演詳細では、補足より上に購入ページを表示します。
- **公式告知の詳細**：公式サイトの告知と照合できた公演に、出演時間・特典会時間と、イベント固有の特典・参加条件・注意事項を表示します。告知全文や共通案内は省き、補足を短い箇条書きにまとめます。記載のない時間は「未掲載」とし、確認日時も表示します。
- **公式リンク**：トップページから公式サイト・公式Xを開けます。該当する公式告知に投稿URLがある場合は、その公演の公式X投稿へ直接移動できます。
- **地図**：会場名をタップすると地図で検索できます。

### 対象の出演者

ゆるめるモ！に加え、なに・ねるん・へそ・めあり・らき・まことの個人出演、なにぬねるん・へくしょんめくしょん・ねるんポクぽく・なにQのユニット出演、桃組暴想族・Babywiper or Gangsterのユニット出演を対象にしています。個人名だけの公演は、所属表記または公式告知の購入先と開催日で対象を確認できた場合に取得します。

### 対応サイト・更新のタイミング

TicketDive・LivePocket・TIGET・イープラスに対応しています。Buzzチケ・ローチケは現在対象外です。

アプリを開いたとき、ほかのアプリから戻ったとき、手動更新したときに情報を取得します。**アプリを閉じている間の取得・通知はありません。** 開いたままでも定期更新は行いません。

公式情報はサイトに現在表示されるカレンダー本文を利用します。X投稿・画像内の文字の自動取得には対応していません。公式情報の取得に失敗した場合は、前回情報と確認日時を表示します。

お気に入り・既読状態・前回の情報は端末内に保存します。端末間の同期はなく、アプリの削除・データ消去で失われます。取得に失敗した場合は前回の情報を「前回取得」として表示するため、設定画面の取得状況と購入先も確認してください。
