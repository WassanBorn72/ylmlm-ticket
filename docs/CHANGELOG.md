# 更新履歴

## v0.6.0

- 出演者をグループ・個人・グループ内ユニット・外部コラボから選ぶ絞り込みを追加。日付・検索・新着・お気に入りと併用可能。
- 桃組暴想族と Babywiper or Gangster の公演を取得対象に追加。Gangstar 表記も同じ対象として照合。
- 一覧・詳細で外部コラボを区別し、出演者選択と併せてユニット名を表示。
- 個人の絞り込みにはユニット出演を自動で含めず、誤った出演情報の表示を抑制。

## v0.5.0

- なに・ねるん・へそ・めあり・らき・まことの個人出演、なにぬねるん・へくしょんめくしょん・ねるんポクぽく・なにQのユニット出演を対象に追加。
- 所属表記や公式カレンダーの購入先・開催日を照合し、短い個人名の部分一致による誤検出を抑制。
- 出演者名での検索と、一覧・詳細の出演者表示に対応。
- 複数の検索を巡回しつつ、公演URLの重複取得と一覧の重複表示を抑制。

## v0.4.1

- 公演詳細の購入先を補足より上へ移動。
- 公式サイト・公式Xへの共通リンクをトップページに集約。
- 詳細の公式カレンダーリンクを削除し、該当公演の公式X投稿リンクだけを表示。

## v0.4.0

- 公演詳細に公式サイト・公式Xへのリンクを追加。公式告知と照合できない公演からも利用可能。
- 照合した公式告知に公式アカウントの投稿URLがある場合、その公演のX投稿を直接開けるように改善。投稿リンクを推測せず、他アカウント・別公演のリンクは付与しない。
- X APIや有料サービスを使用せず、追加の取得費用は不要。

## v0.3.0

- 公式サイトのカレンダー告知をチケット掲載公演と照合し、出演時間・特典会時間・確認元リンク・確認日時を詳細に追加。
- 補足はイベント固有の特典・参加条件・注意事項を箇条書きで表示し、告知全文・共通案内・重複する基本情報を省略。券種限定の特典には対象券種を明記。
- 公式情報の取得失敗時は前回情報と確認日時を保持。曖昧な告知を付与せず、未掲載の時間を推測しない。
- 設定画面にアプリのバージョンを表示。バージョン表記を新機能の追加に合わせて0.3.0に整理。

## v0.2.6

- Android正式版をGitHub Releasesで初公開。
- 4サイトのチケット取得、公演一覧・詳細、検索・日付絞り込み、お気に入り、新着・既読、地図検索に対応。
