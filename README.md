# モ！のチケット帳（非公式）

ゆるめるモ！とメンバー・ユニットのチケット情報をまとめて確認できる、非公式アプリです。会場・チケット代・開場／開演時間を一覧で確認し、購入先のページへ移動できます。

**ゆるめるモ！および各チケットサイトの公式アプリではありません。** 購入前に、料金・日時・販売状況をチケットサイトで確認してください。

## ダウンロード

### Android

正式版 **v0.5.0** を公開しています。6人の個人出演と4ユニットの出演に対応しました。

**[Androidアプリをダウンロード](https://github.com/WassanBorn72/ylmlm-ticket/releases/download/v0.5.0/ylmlm-unofficial-ticket-v0.5.0.apk)** · [リリース一覧](https://github.com/WassanBorn72/ylmlm-ticket/releases)

1. AndroidスマホでAPKをダウンロードします。
2. ダウンロードした `ylmlm-unofficial-ticket-v0.5.0.apk` を開きます。
3. インストール許可を求められたら、ブラウザーや「Files」など今回使う提供元を許可します。
4. 「モ！のチケット帳（非公式）」を開きます。

更新時は、新しい正式版APKを上書きインストールしてください。お気に入りを残すため、先にアンインストールする必要はありません。

### iPhone

現在、ダウンロードしてそのままインストールできるiPhone版は配布していません。MacとXcode、Apple IDがあれば、ご自身のiPhone向けにビルドして利用できます。無料Apple IDの署名は通常7日で期限切れになるため、再ビルドが必要です。

詳しくは [iPhoneへのインストール手順](docs/IOS.md) を参照してください。

## 使い方

- **公演を探す**：公演名・会場名で検索できます。「日付で絞り込む」からカレンダーを開くと、公演のある日に印が付きます。日付を選んで絞り込み、「解除」で一覧に戻せます。
- **詳細と購入先を確認する**：公演を開くと、会場・券種別料金・開場／開演時間・購入先を確認できます。購入先を公式告知の補足より上に表示します。不明な料金は「購入先で確認」、時間は「未掲載」と表示します。
- **会場への行き方を調べる**：会場名をタップすると地図を開きます。住所がない場合は会場名で検索します。
- **お気に入りに登録する**：ハートを押すと登録・解除できます。「お気に入り」には掲載中の登録公演を表示します。
- **新着を見る**：初回の取得では新着にしません。その後、新しく見つかった公演を `NEW` と「新着」に表示します。価格変更や同じ公演の別サイト掲載は新着にしません。
- **最新情報に更新する**：アプリを開いたとき、ほかのアプリから戻ったとき、手動更新したときに情報を取得します。

**アプリを閉じている間の取得・通知はありません。** 開いたままでも定期更新は行いません。新着は次に開いたとき／更新したときに確認できます。

## 出演時間・特典会とイベント固有の補足

チケットサイトの公演と、ゆるめるモ！公式サイトのカレンダーにある告知を照合し、公演詳細に以下を追加します。

- **出演時間・特典会時間**：告知に書かれた時間を表示します。記載がない場合は「未掲載」です。
- **その他補足**：券種限定の特典、仮装、当日支払い、再入場・撮影の条件などを短い箇条書きで表示します。券種限定の特典は、対象券種も明記します。
- **公式情報の確認日時**：公式情報を確認した日時を表示します。

公式サイト・公式Xへの共通リンクはトップページにあります。公式サイトの該当告知に公式Xの投稿URLがある場合は、その公演の投稿へ直接移動できます。X APIや追加費用は不要です。

公演名・開催日・購入先などから同じ公演だと照合できた場合に表示します。告知全文や共通案内、一覧と重複する料金・時間・出演者一覧は補足に載せません。情報を推測して埋めることはありません。

公式サイトに現在表示されているカレンダー本文が対象です。X投稿や画像内のタイムテーブルの自動取得には対応していません。公式情報の取得に失敗した場合は、前回の公式情報と確認日時を表示します。

## 個人・ユニット出演

なに・ねるん・へそ・めあり・らき・まことの個人出演と、なにぬねるん・へくしょんめくしょん・ねるんポクぽく・なにQのユニット出演も対象です。個人名だけで所属が確認できない公演は、公式カレンダーの購入先と開催日が一致する場合に取り込みます。ユニット名でも検索し、一覧・詳細に対象の出演者を表示し、出演者名でも検索できます。全公演を必ず網羅できるものではありません。

## 対応チケットサイト

[TicketDive](https://ticketdive.com/)・[LivePocket](https://livepocket.jp/)・[TIGET](https://tiget.net/)・[イープラス](https://eplus.jp/)に対応しています。Buzzチケ・ローチケは現在対象外です。イープラスはグループ専用一覧と、公式告知に掲載された個別公演リンクを取得します。

過去公演や、取得に成功したサイトの一覧から消えた公演は表示しません。完売でもページが一覧に残っていれば表示するため、販売状況は購入先で確認してください。

## 保存データと、取得できない場合

ユーザー登録は不要です。お気に入り・新着の既読状態・前回の取得情報は、この端末内に保存します。端末間の同期はなく、アプリの削除やデータ消去で失われます。

通信やサイト側の制限で取得できない場合は、前回の情報を「前回取得」として表示します。設定画面で取得状況を確認し、時間を置いて更新するか、チケットサイトを直接開いてください。サイトの変更によって、情報を正しく取得できなくなる場合もあります。

Android／iPhone実機での接続検証結果は、まだ記録されていません。サイト側の制限により、ご利用の回線では取得できない場合があります。

### 次回アップデートに向けた変更

出演者をグループ・個人・グループ内ユニット・外部コラボから選択し、日付や検索、お気に入りと併用して絞り込めます。個人の選択にユニット出演は自動で含めません。桃組暴想族、Babywiper or Gangster（Gangstar 表記にも対応）を外部コラボとして追加しました。掲載された公演のみを表示し、参加メンバーは桃組暴想族がねるん、Babywiper or Gangsterがめありと表示します。活動継続や公演ごとの出演変更は推測せず、購入先でご確認ください。この変更は現在のソースに含まれ、公開 APK は v0.5.0 のままです。
