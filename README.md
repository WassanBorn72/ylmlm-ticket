# モ！のチケット帳（非公式）

ゆるめるモ！とメンバー・ユニットのチケット情報をまとめて確認できる、非公式アプリです。会場・チケット代・開場／開演時間を確認し、購入先のページへ移動できます。ユーザー登録は不要です。

**ゆるめるモ！および各チケットサイトの公式アプリではありません。** 購入前に、料金・日時・販売状況をチケットサイトで確認してください。

## ダウンロード・インストール

### Android

最新版は **v0.7.3** です。

**[Androidアプリをダウンロード](https://github.com/WassanBorn72/ylmlm-ticket/releases/download/v0.7.3/ylmlm-unofficial-ticket-v0.7.3.apk)**

1. Androidスマホで上のリンクからAPKをダウンロードします。
2. ダウンロードした `ylmlm-unofficial-ticket-v0.7.3.apk` を開きます。
3. インストール許可を求められたら、ブラウザーや「Files」など今回使う提供元を許可します。
4. 「モ！のチケット帳（非公式）」を開きます。

更新時は新しいAPKを上書きインストールしてください。お気に入りを残すため、先にアンインストールする必要はありません。

今後の最新版は [GitHub Releases](https://github.com/WassanBorn72/ylmlm-ticket/releases/latest) から取得できます。アプリのバージョンは設定画面で確認できます。[更新履歴](docs/CHANGELOG.md)も参照してください。

### iPhone

現在、ダウンロードしてそのままインストールできるiPhone版は配布していません。Mac・Xcode・Apple IDがあれば、ご自身のiPhone向けにビルドして利用できます。無料Apple IDの署名は通常7日で期限切れになるため、再ビルドが必要です。

詳しくは [iPhoneへのインストール手順](docs/IOS.md) を参照してください。

## 使い方

- **公演を探す**：公演名・会場名・出演者名で検索できます。
- **出演者で絞り込む**：「出演者で絞り込む」からグループ・個人・ユニットを選べます。個人を選んだ場合、そのメンバーのユニット出演は自動では含めません。
- **日付で絞り込む**：カレンダーで開催日を選べます。公演のある日に印が付き、「解除」で日付の絞り込みを外せます。出演者・検索・お気に入りと併用できます。
- **詳細と購入先を確認する**：公演を開くと、会場・券種別料金・開場／開演時間・購入先を確認できます。不明な料金は「購入先で確認」、時間は「未掲載」と表示します。
- **販売状況を確認する**：一覧に販売状況、詳細に券種ごとの状況・取得できた受付期間を表示します。完売と受付終了を区別し、不明な情報は「購入先で確認」とします。
- **カレンダーに追加する**：公演詳細の上部にある大きな「カレンダーに追加」ボタンから、端末の予定編集画面を開けます。出演時間・特典会時間・補足・購入先は、取得できているものをメモ欄に入れます。予定はOPEN（開場）時間から開始します。開場未掲載なら開演時間、両方未掲載なら終日予定にします。終了時刻は予定の開始から1時間を仮設定します。保存前に内容を確認・編集してください。保存後の自動同期はありません。
- **会場への行き方を調べる**：会場名をタップすると地図を開きます。住所がない場合は会場名で検索します。
- **お気に入りに登録する**：ハートで登録・解除できます。「お気に入り」には掲載中の登録公演を表示します。
- **お気に入りの変更を確認する**：次回の正常取得時に料金・開場／開演時間・販売状況・受付期間の変更前後を表示します。「変更を確認しました」で表示を消せます。未掲載の値や複数公演を区別できない場合は変更を判定しません。
- **発売開始を通知する**：公演詳細・お気に入りタブ・設定画面の「発売開始通知」スイッチをオンにして、端末の通知を許可してください。取得できた未来の発売日時を、近い順に最大50件予約します。同じ公演・同じ時刻の券種はまとめて通知し、通知をタップすると公演詳細を開きます。
- **新着を見る**：初回取得後、新しく見つかった公演を `NEW` と「新着」に表示します。初回取得、価格変更、同じ公演の別サイト掲載は新着にしません。

### 公式告知の詳細

公式サイトのカレンダー告知と照合できた公演には、次の情報を追加します。

- **出演時間・特典会時間**：告知に書かれた時間を表示します。記載がない場合は「未掲載」です。
- **その他補足**：券種限定の特典、仮装、当日支払い、再入場・撮影の条件など、その公演固有の情報を短い箇条書きで表示します。券種限定の特典は対象券種も明記します。
- **公式情報の確認日時**：情報を確認した日時を表示します。

購入先は補足より上に表示します。告知全文・共通案内・基本情報の重複は補足に載せず、不明な情報を推測して埋めることはありません。

公式サイト・公式Xへの共通リンクはトップページにあります。該当する公式告知に公式Xの投稿URLがある場合は、公演詳細からその投稿を直接開けます。

ブラウザー版のカレンダー追加はGoogleカレンダーの編集画面を開きます。

## 対応する出演者・チケットサイト

### 出演者

| 区分 | 対象 |
| --- | --- |
| グループ | ゆるめるモ！ |
| 個人 | なに・ねるん・へそ・めあり・らき・まこと |
| ユニット | なにぬねるん？・へくしょんめくしょん・ねるんポクぽく・なにQ・桃組暴想族・Babywiper or Gangster |

個人出演は、所属表記または公式カレンダーの購入先と開催日で対象を確認できた場合に取得します。すべての公演を必ず網羅できるものではありません。ユニットの活動継続や公演ごとの出演変更は推測せず、購入先でご確認ください。

### チケットサイト

[TicketDive](https://ticketdive.com/)・[LivePocket](https://livepocket.jp/)・[TIGET](https://tiget.net/)・[イープラス](https://eplus.jp/)に対応しています。Buzzチケ・ローチケは現在対象外です。

過去公演や、取得に成功したサイトの一覧から消えた公演は表示しません。完売でもページが一覧に残っていれば表示するため、販売状況は購入先で確認してください。

## Androidのホーム画面ウィジェット

ホーム画面を長押しして、ウィジェット一覧の「モ！のチケット帳（非公式）」から次の2種類を選べます。アプリの設定画面から追加を依頼することもできます。

- **お気に入りの公演**：掲載中のお気に入りから直近の予定を表示します。
- **直近の公演**：全公演から直近の予定を表示します。

サイズに応じて最大6公演を自動表示し、公演をタップすると詳細を開きます。日付を大きく、公演名・OPEN時間（未掲載なら開演時間）・会場を行に分けて表示します。情報の取得時刻は下部で確認できます。ウィジェット自身はチケットサイトに接続せず、アプリで取得・保存した情報を使います。最新情報はアプリを開いて更新してください。iPhone・ブラウザー版のウィジェットは対象外です。

## 更新のタイミング・情報の範囲

アプリを開いたとき、ほかのアプリから戻ったとき、手動更新したときに情報を取得します。前回の保存情報を先に表示し、取得できたサイトから順に更新します。公式告知との照合が完了するまでは更新中と表示し、全体の終了を待たずに公演を確認できます。更新中は「中止」で通信を中断でき、前回の情報は残ります。

**アプリを閉じている間は新しい情報を取得しません。** 発売開始リマインダーを有効にした場合、取得済みの発売日時は端末から通知できます。 開いたままでも定期更新は行いません。新着は次に開いたとき、または更新したときに確認できます。

公式情報は、公式サイトに現在表示されているカレンダー本文が対象です。X投稿や画像内のタイムテーブルの自動取得には対応していません。

### 発売開始リマインダーの注意点

初期設定はオフです。お気に入り解除・通知オフ・取得時に分かった発売日時の変更は予約に反映します。日時未掲載・開始済み・完売・受付終了の券種は新たに予約しません。取得できないサイトの前回予約は保持します。日時変更を反映するにはアプリを開いて再取得する必要があります。まだ取得していない新しい公演の通知はできません。

省電力設定や端末の状態によって通知が遅れる場合があります。ブラウザー版では通知できません。端末の設定で通知を拒否した場合は、設定画面から許可して予約を再試行してください。

## 保存データ・取得できない場合

お気に入り・新着の既読状態・前回の取得情報は、この端末内に保存します。端末間の同期はなく、アプリの削除やデータ消去で失われます。

通信やサイト側の制限で取得できない場合は、前回の情報を「前回取得」として表示します。公式情報も取得に失敗した場合は、前回の情報と確認日時を表示します。設定画面で取得状況を確認し、時間を置いて更新するか、チケットサイトを直接開いてください。

サイトの変更や、ご利用の回線に対する制限によって、情報を正しく取得できなくなる場合があります。
