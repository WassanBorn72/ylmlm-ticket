# モ！のチケット帳（非公式）

ゆるめるモ！のチケット情報をまとめて確認できる、非公式アプリです。会場・チケット代・開場／開演時間を一覧で確認し、購入先のページへ移動できます。

**ゆるめるモ！および各チケットサイトの公式アプリではありません。** 購入前に、料金・日時・販売状況をチケットサイトで確認してください。

## ダウンロード

### Android

正式版 **v0.2.6** をGitHubで公開しています。

**[Androidアプリをダウンロード](https://github.com/WassanBorn72/ylmlm-ticket/releases/download/v0.2.6/ylmlm-unofficial-ticket-v0.2.6.apk)** · [リリース一覧](https://github.com/WassanBorn72/ylmlm-ticket/releases)

1. AndroidスマホでAPKをダウンロードします。
2. ダウンロードした `ylmlm-unofficial-ticket-v0.2.6.apk` を開きます。
3. インストール許可を求められたら、ブラウザーや「Files」など今回使う提供元を許可します。
4. 「モ！のチケット帳（非公式）」を開きます。

更新時は、新しい正式版APKを上書きインストールしてください。お気に入りを残すため、先にアンインストールする必要はありません。

### iPhone

現在、ダウンロードしてそのままインストールできるiPhone版は配布していません。MacとXcode、Apple IDがあれば、ご自身のiPhone向けにビルドして利用できます。無料Apple IDの署名は通常7日で期限切れになるため、再ビルドが必要です。

詳しくは [iPhoneへのインストール手順](docs/IOS.md) を参照してください。

## 使い方

- **公演を探す**：公演名・会場名で検索できます。「日付で絞り込む」からカレンダーを開くと、公演のある日に印が付きます。日付を選んで絞り込み、「解除」で一覧に戻せます。
- **詳細と購入先を確認する**：公演を開くと、会場・券種別料金・開場／開演時間・購入先を確認できます。不明な料金は「購入先で確認」、時間は「未掲載」と表示します。
- **会場への行き方を調べる**：会場名をタップすると地図を開きます。住所がない場合は会場名で検索します。
- **お気に入りに登録する**：ハートを押すと登録・解除できます。「お気に入り」には掲載中の登録公演を表示します。
- **新着を見る**：初回の取得では新着にしません。その後、新しく見つかった公演を `NEW` と「新着」に表示します。価格変更や同じ公演の別サイト掲載は新着にしません。
- **最新情報に更新する**：アプリを開いたとき、ほかのアプリから戻ったとき、手動更新したときに情報を取得します。

**アプリを閉じている間の取得・通知はありません。** 開いたままでも定期更新は行いません。新着は次に開いたとき／更新したときに確認できます。

次版 **v0.2.7（公開準備中）** では、チケット掲載公演と照合できた公式サイトの告知を詳細へ追加します。出演時間・特典会時間・その他補足と確認元リンクを表示します。時間が書かれていない場合は「未掲載」です。X投稿や画像内の文字の自動取得には対応していません。

## 対応チケットサイト

[TicketDive](https://ticketdive.com/)・[LivePocket](https://livepocket.jp/)・[TIGET](https://tiget.net/)・[イープラス](https://eplus.jp/)に対応しています。Buzzチケ・ローチケは現在対象外です。

過去公演や、取得に成功したサイトの一覧から消えた公演は表示しません。完売でもページが一覧に残っていれば表示するため、販売状況は購入先で確認してください。

## 保存データと、取得できない場合

ユーザー登録は不要です。お気に入り・新着の既読状態・前回の取得情報は、この端末内に保存します。端末間の同期はなく、アプリの削除やデータ消去で失われます。

通信やサイト側の制限で取得できない場合は、前回の情報を「前回取得」として表示します。設定画面で取得状況を確認し、時間を置いて更新するか、チケットサイトを直接開いてください。サイトの変更によって、情報を正しく取得できなくなる場合もあります。

Android／iPhone実機での接続検証結果は、まだ記録されていません。サイト側の制限により、ご利用の回線では取得できない場合があります。

## 不具合・要望

[GitHub Issues](https://github.com/WassanBorn72/ylmlm-ticket/issues)へ、アプリのバージョン、端末・OS、起きたこと、該当するチケットページのURLを添えてお知らせください。個人情報やパスワードは記載しないでください。
